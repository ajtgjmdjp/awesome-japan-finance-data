# Contributing to Awesome Japan Finance Data

Thank you for contributing!

## Guidelines

1. **Verify all information against primary sources.** Don't rely on memory or secondary sources for API endpoints, pricing, terms of use, etc.

2. **One data source per pull request.** This makes review easier.

3. **Include these details for each entry:**
   - Official URL
   - Data types available
   - Authentication requirements
   - Pricing (free tier if applicable)
   - Format (API, CSV, HTML, etc.)
   - Terms of use summary
   - Python libraries (if any)

4. **Alphabetical order** within each section.

5. **Link to primary sources** for terms of use, API documentation, and pricing.

## What to Add

- Official Japanese government data sources
- Financial APIs with Japanese market coverage
- Python libraries for Japanese financial data
- MCP tools for Japanese finance
- Benchmarks and datasets related to Japanese finance

## What NOT to Add

- Tools that only scrape websites in violation of their terms
- Paid-only services without a free tier (unless they are the primary/official source)
- Unmaintained projects (no commits in 2+ years)
- Projects with fewer than 0 stars (unless they are official tools)
